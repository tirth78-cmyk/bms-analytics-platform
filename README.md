# BMS Omnichannel Content Analytics Platform

**Interactive analytics dashboard for BMS commercial content intelligence — built by Improzo.**

## Live Demo
🔗 [https://tirthankarray.github.io/bms-analytics-platform/](https://tirthankarray.github.io/bms-analytics-platform/)

## Features

| Dashboard | Description |
|-----------|-------------|
| **Executive** | Portfolio KPIs, brand engagement, channel CPC efficiency |
| **Content Performance** | Content type effectiveness, personalization impact analysis |
| **HCP Journey** | NBA acceptance rates, journey outcome funnel, channel effectiveness |
| **Competitive** | Share of voice, BMS vs competitor engagement rates |
| **A/B Testing** | Test program results, lift analysis, impact estimation |
| **MLR Compliance** | Approval velocity, rejection reasons, regulatory bottlenecks |
| **ROI & Budget** | Channel ROI, ROAS, budget reallocation intelligence |
| **Sentiment** | Brand sentiment, prescribing intent, NLP-powered insights |
| **Channel Mix** | Current vs optimal allocation, rebalancing recommendations |
| **Data Flow** | Full architecture diagram, source catalog, medallion pipeline, governance |

## Tech Stack
- React 18 + Vite
- Recharts for data visualization
- Tailwind CSS
- Lucide React icons
- GitHub Pages (auto-deploy via Actions)

## Data Scope
- **12 BMS Brands**: Opdivo, Eliquis, Reblozyl, Breyanzi, Camzyos, Sotyktu, Zeposia, and more
- **20 Markets**: US, EU5, Japan, Canada, Australia, LATAM, APAC, MENA
- **20 Channels**: Email, eDetailer, Social, CTV, Programmatic, Congress, KOL Video, etc.
- **Reporting Period**: Jan 2025 – Mar 2026

## Local Development
```bash
npm install
npm run dev
```

## Deployment
Push to `main` branch → GitHub Actions auto-builds and deploys to Pages.
